== Model coverage

Every face family of the
link:../_references/processing-model[processing model] is governed on
every adapter: **equivalent** by contract, **loud** (a named raise), or
a **registered divergence**. The table below is generated from the
coverage matrix that the consistency audit enforces, so the published
proof cannot drift from the tested proof.

The evidence chain is checkable at every link: the model section names
the specs that enforce it (`Pins::`), each enforcing spec cites the
model section, the matrix maps every face family to its section and
pin, and the divergence IDs resolve in
link:divergences.html[the register].

== Reproducing

`bundle exec rake docs:coverage` regenerates the block above from
`spec/support/model_coverage.rb`. `spec/consistency/published_docs_spec.rb`
fails when the published block is stale; the consistency suite runs it
on every CI build.

The performance commitment has its own published page:
link:performance.html[Performance], regenerated from the scoreboard
harness at release time.
